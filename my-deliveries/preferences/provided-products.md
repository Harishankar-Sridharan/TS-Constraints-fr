# Produits fournis

Cette contrainte spécifie les types de produits auxquels une ressource doit avoir accès pour effectuer une visite sur un site donné.

**Format :** Liste de textes, chaque élément séparé par des virgules.

**Exemple :**\
Si une ressource doit s'arrêter dans un dépôt pour récupérer des outils de jardinage avant d'effectuer une visite, vous pouvez spécifier **"jardinage"** comme le produit requis.\
Au moins un dépôt doit fournir ce produit pour que la ressource puisse effectuer la visite.
