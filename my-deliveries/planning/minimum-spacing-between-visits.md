# Espacement minimum entre les visites

Cette contrainte spécifie le **nombre minimum de jours requis entre deux visites** au même client.

**Format :** Entier

**Remarque :** Si la fréquence de visite comporte plus d'une récurrence, cette contrainte est **non appliquée**.

**Exemple :**

* **Fréquence des visites :** 1/5
* **Espacement minimum entre les visites :** 3 jours
* **Jours travaillés :** 1–15

Pour maintenir un intervalle de 2 jours entre les visites, le client devrait être visité les **jours 5, 9 et 12**, plutôt que les jours 5, 8 et 11.
