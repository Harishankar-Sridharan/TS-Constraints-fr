# Nombre maximum de rechargements/déchargements

Cette contrainte vous permet de **limiter le nombre de rechargements par jour** lorsque le rechargement est autorisé par le **Recharger/Décharger** contrainte. Il définit le nombre maximal d'opérations de rechargement qu'une ressource peut effectuer en une seule journée.

**Format :** Nombre

**Exemple**: HH MM

**Remarque :** Cette contrainte dépend de la **capacité du véhicule**.
