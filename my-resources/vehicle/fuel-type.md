# Type de carburant

**Cette valeur définit le type de carburant utilisé par la ressource ou le véhicule.**\
Elle aide à optimiser les itinéraires et les calculs en fonction du type de carburant, de la consommation et des contraintes associées. Les types de carburant courants incluent l'essence, le diesel, l'électrique ou l'hybride.

\
**Format :** Texte (caractères)\
**Valeur par défaut :** _Diesel_ (selon la configuration du système)

**Exemple :**\
_**Carburant** – Électrique_
