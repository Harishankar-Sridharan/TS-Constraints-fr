# Toutes les compatibilités

Lorsque le **Compatibilité avec les ressources** une contrainte est appliquée (en particulier avec plusieurs critères), ce paramètre vous permet de spécifier si **une seule** un critère de la liste suffit ou si **tous les critères** doivent être remplis.

**Format :** Oui / Non

**Exemple :** Toutes compatibilités - Non
