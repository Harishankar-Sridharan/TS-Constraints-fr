# Nom

Cette valeur est utilisée pour identifier de manière unique le dépôt. Le nom peut être le nom/identifiant du dépôt/entrepôt.&#x20;

**Format :** caractère

**Exemples :**

* Dépôt A

L'attribution d'une valeur à ce champ est **obligatoire**, et il est recommandé d'utiliser un **nom unique** pour chaque site afin d'éviter toute confusion lors de la planification.
